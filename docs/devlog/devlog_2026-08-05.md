# 2026-08-05 开发日志：星际矿区配置化与跨星球隔离

今天将星际矿区从“哈奇星球写死功能”重构为可由星球 JSON 启用的独立玩法能力。改造范围限定在矿区入口、iframe 通讯、派遣互斥、矿区 bridge、子页存档和矿石内容包；哈奇远征、探索档案、家园珍宝和远征结算仍保持哈奇专属，避免仅启用矿区的其他星球误获得远征能力。

本轮未提交、推送或上传资源。

## 已完成：星球玩法开关

新增 `js/planet_features.js`，从 `famous-planets/_planet_index.json` 读取星球的 `features`。当前约定：

```json
{
  "id": "some-planet",
  "features": ["mineralExploration"]
}
```

当当前星球包含 `mineralExploration` 时，主页显示“星际矿区”，且矿区路由允许创建 iframe。未配置该能力的星球不会出现入口，也不能通过路由绕过门禁进入玩法。

哈奇条目已启用该能力。保留哈奇作为加载前或配置读取失败时的兼容回退，避免既有哈奇入口因为异步索引读取短暂消失。

## 已完成：按 planetId 隔离矿区状态

宿主 bridge 从单一 `settings.haqiMineralBridge` 收敛为：

```text
state.settings.mineralExplorationBridges[planetId]
```

每套 bridge 独立保存派遣宠物、博物馆 Buff、研究线索、路线芯片、请求去重记录及同步时间。旧玩家第一次读取哈奇 bridge 时，会自动把旧 `haqiMineralBridge` 迁移到 `mineralExplorationBridges.haqi`，不丢失已存在的矿区进度。

派遣互斥判定不再拒绝非哈奇星球，而是读取当前星球对应 bridge；因此同一只伙伴在不同星球的矿区派遣不会共享状态。

矿区子页 localStorage 键同步改为：

```text
magichaqi:mineral-exploration:v1:<planetId>:<userId>
```

不同星球的勘探、原石、鉴定、博物馆、熔炉和奇遇存档彼此隔离。

## 已完成：通用 iframe 协议

宿主创建矿区 iframe 时将当前 `planetId` 放进查询参数；子页读取并规范化该 ID。`HOST_READY`、`BRIDGE_SNAPSHOT`、`DISPATCH_STATUS_SYNC`、`GLOBAL_BONUS_SYNC`、`REQUEST_ROUTE_PREPARATION` 和 `ROUTE_PREPARATION_RESULT` 均携带当前星球 ID。

宿主继续校验 channel、version、当前星球、iframe 来源和请求 ID。真实背包、路线芯片材料扣除和最终远征结算依旧只在宿主侧执行，独立 `file://` 预览页不具有资产写入权限。

## 已完成：JSON 矿石内容包接线

哈奇星球配置新增：

```json
{
  "mineralExploration": {
    "contentPacks": ["content/haqi_minerals_abyssal_echoes.json"]
  }
}
```

宿主会在 `HOST_READY` 中传递 `contentPacks`，子页只接受 `content/*.json` 相对路径，并在握手后加载内容包。正式内容包会替换演示矿石和演示系列，并筛除引用已被替换演示矿石的基础配方；矿石缺少视觉字段时使用稀有度默认视觉，鉴定来源缺少权重时采用 R `12`、SR `4`、SSR `1` 的默认权重。内容包加载失败时保留基础矿池，避免离线或资源异常让矿区不可用。

已接入深海回音、熔岩地核、废土朋克、远古星核四个内容包，每包包含 10 种矿石、一个博物馆系列和对应 UR 配方。正式哈奇配置共提供 40 种矿石和 4 个系列，避免演示数据叠加后意外变成 44 种矿石、6 个系列。

## 已完成：SDET 测试与本地 GM 工具

新增纯规则模块 `js/expedition_tactical_core.js`，将偏导护盾和紧急救援信标从 DOM 与 `GameManager` 依赖中抽离为可确定性测试的逻辑。远征页在创建 `GameManager` 前动态加载该模块；加载异常时使用等价的本地降级逻辑，避免单个模块资源失败阻断游戏启动。

远征页移除了早期残留的战术原型包装器。此前该包装器仍处于最终包装器调用链中，会导致偏导护盾被重复施加；现在战术效果仅在最终包装器中执行一次。

新增测试：

- `tests/pet_breeding_catalysts.test.mjs`：验证 SSR x SSR 使用突变催化剂后，UR 突变概率为 25%；验证 UR 属性锁将指定 IV 保底至 80，且不改变其他 IV。
- `tests/expedition_tactical_core.test.mjs`：验证偏导护盾提供最大生命 45% 的护盾；紧急救援信标在首次致命伤时恢复最大生命 25% 并提供 20% 护盾；远征已结束时不会拦截失败结算。

矿区 iframe 公开本地调试对象 `window.__haqiDebug`：

```js
__haqiDebug.giveAllMinerals()
__haqiDebug.triggerEncounter()
__haqiDebug.fastForwardDispatch()
```

`giveAllMinerals()` 会为当前内容池中每种矿石写入 100 个数量，并同步博物馆、熔炉和宿主 Buff；`triggerEncounter()` 为一支进行中的勘探队强制创建或打开通讯奇遇；`fastForwardDispatch()` 将所有派遣推进至可领取状态，并将尚未触发的奇遇标记为已解决，便于直接验收奖励领取流程。

图鉴分页保持每页 24 项，因此 40 种矿石会按 24 项与 16 项分为两页。博物馆与远征星图 Buff 预览增加了长文本换行保护；四个系列全部激活时，聚合加成为攻击力 +36%、材料掉落 +40%。
