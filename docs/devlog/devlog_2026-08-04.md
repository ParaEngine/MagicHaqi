# 2026-08-04 开发日志：哈奇星球矿区、远征与探索档案

今天完成了哈奇星球新手任务隔离、星际矿区 Phase 0–5、封板内容扩展约定、稳定性 P0、矿区与远征正式联动，以及 P1 探索档案和本周航线。矿区从独立玩法变为能真实改善哈奇远征的闭环；所有涉及远征、矿区、装备和家园珍宝的入口保持 `planetId === 'haqi'` 门禁，不影响蛋蛋星球。

本轮未执行构建、启动开发服务器、提交或推送。

## 已完成：新手任务按星球隔离

此前哈奇的远征导向任务与蛋蛋星球共用一套 onboarding 配置，导致蛋蛋星球出现无法完成的远征要求。现已按星球拆分：哈奇保留查看伙伴、改名、建设、首次远征、查看远征记录五步目标；蛋蛋星球使用自身养成目标，不再出现哈奇专属远征任务。两颗星球的进度、奖励领取与抽屉状态均独立保存。

## 已完成：星际矿区 Phase 0–5

### Phase 0：副本架构与桥接边界

星际矿区以独立 iframe 副本运行。派遣、原石、矿石收藏、博物馆、配方、奇遇与研究线索保存在副本 localStorage；主应用仅保存最小桥接摘要：revision、派遣宠物 ID、激活系列、全局 Buff、研究线索、路线侦测芯片、已消费请求 ID 与同步时间。报文校验 channel、版本、星球 ID 与 iframe 来源；`file://` 环境以 `event.source` 保障来源校验。

### Phase 1：闲置勘探闭环

已完成浅层矿脉、中层遗迹、深空黑洞三档派遣。伙伴在家的情况下可派遣，副本显示实时倒计时，完成后领取未鉴定原石。派遣状态同步回主应用，因此该伙伴不能同时参加远征、繁育或其他选择器；刷新后仍可恢复限制。

### Phase 2：原石鉴定与图鉴

已完成 1.2 秒鉴定动画和矿石图鉴。原石会随机产出 R 熔心碎晶、SR 幽潮蓝晶、SSR 极光辉石，并记录数量与首次获得时间；隐藏 UR 日冕星核棱晶不在普通鉴定权重池中。

### Phase 3：星际博物馆

已完成核心测试系列：集齐三种基础矿石激活 `3/3`，同步全队攻击力 `+5%`。副本在加载与鉴定后从矿石收藏重算完成系列和全局 Buff，再发送完整同步摘要，避免旧档或增量同步导致奖励错误。

### Phase 4：矿石熔炉与隐藏配方

已完成熔炉与隐藏 UR 配方：消耗熔心碎晶 `x3`、幽潮蓝晶 `x1`，经过 1.25 秒熔炼后产出日冕星核棱晶，精确扣材并保存配方发现记录。UR 在图鉴和获得卡片中使用独立彩色边框与光晕，熔炼后会重新计算博物馆。

### Phase 5：奇遇通讯与事件抉择

已完成派遣半程概率触发的“神秘晶洞”通讯。冒险进入可能获得 `+2` 原石与 2 点研究线索，也可能只带回 1 点线索；谨慎绕行稳定获得 `+1` 原石与 1 点线索。奇遇待处理时会拦截领奖，选择后写入副本状态并恢复领取入口。

矿区派遣、领取、鉴定、收藏、博物馆、合成、隐藏 UR、奇遇与宿主桥接已封板。后续矿石、系列、配方和奇遇优先通过 JSON 内容包扩展，第一批“深海回音”内容位于 `content/haqi_minerals_abyssal_echoes.json`，包含 10 种矿石、博物馆奖励与 UR 配方。

已完成 P0 稳定性基础：localStorage 保存时以 revision 乐观比较避免旧标签直接覆盖新状态；鉴定与熔炼先提交资产、动画只处理 pending 标记，降低动画中断丢资产风险；矿区页面补齐移动端安全区适配。浏览器 localStorage 不具备真正跨标签原子事务，因此冲突时会重新读取并要求玩家重试，而不伪称完全无竞争。

## 已完成：博物馆 Buff 接入真实远征

远征统一通过 `getHaqiMineralBridge()` 读取桥接摘要，不直接读取矿区 localStorage。发射时，主应用在装备、成长与训练属性计算完成后，把博物馆攻击加成写入本次 `selectedPet.battleStats.attack` 快照：

```js
const mineralAttackBonus = Math.round(baseAttack * attackPercent / 100);
attack = baseAttack + mineralAttackBonus;
```

小游戏使用这份攻击快照，不会在运行中重复叠加或因桥接变化漂移。材料掉落 Buff 则在宿主最终结算层生效，只放大白名单远征材料，不放大经验、装备、家园珍宝或捕获伙伴。结算保留 `baseAmount`、`bonusAmount` 与最终 `amount`；例如基础 2 份材料在 12% 加成下有 0.24 概率额外获得 1 份。宿主会在结算时重读 bridge Buff，不信任 iframe 回传内容直接决定真实资产。

远征 iframe 已解释博物馆倍率，返航后 Toast 会展示实际材料构成，例如“基础 2 + 博物馆 1，+12%”。

## 已完成：P0 融合闭环

星图发射卡现显示博物馆实际攻击、基础攻击到加成后攻击、材料掉落百分比和路线侦测芯片数量。精英节点标注攻击晶核、守护甲片等研究材料方向；首领标注星核精粹回收方向。提示不改写掉落池，实际资产仍经宿主白名单结算。

远征历史在宿主成功最终结算后写入真实 `result.loot`，包含攻击 Buff、掉落 Buff、基础材料与博物馆额外材料；失败远征不写资产，也不会伪造收益。博物馆增加“星核回收系”，使用幽潮蓝晶、极光辉石和日冕星核棱晶，提供材料掉落 `+5%`，不新增平行货币；页面同时显示当前收益、缺失矿石和下一档解锁效果。

远征材料到矿区通过宿主协议闭环：矿区请求熔炼路线侦测芯片时，宿主核验 iframe 来源、哈奇星球、请求 ID、库存、材料白名单与 3 枚上限，再消耗 `manaDust x2 + attackCore x1` 并回执。请求 ID 只能结算一次。芯片在真实发射时由宿主消费，只点亮当次精英或首领路线目标，不提供攻击、掉落、装备或直接奖励。研究线索同步进桥接摘要。
