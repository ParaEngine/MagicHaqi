## 已完成：重复矿石三条消耗路径

矿石工坊保留原有高价值配方，同时新增两条重复矿石路径。两条新路径均要求同种矿石持有至少 6 枚，仅消耗 5 枚并保留首枚收藏，因此不会破坏图鉴或博物馆进度。

| 稀有度 | 消耗 | 精炼产出 | 出售产出 |
| --- | ---: | ---: | ---: |
| R | 同种重复矿石 x5 | 星核精粹 x1 | 金币 x3 |
| SR | 同种重复矿石 x5 | 星核精粹 x2 | 金币 x6 |
| SSR | 同种重复矿石 x5 | 星核精粹 x3 | 金币 x9 |

三条路径分别是：

- 保留稀有矿石用于系列收藏和永久远征 Buff；
- 使用特定矿石完成 UR、战术道具和繁殖催化剂配方；
- 将重复 R / SR / SSR 矿石精炼为装备强化材料，或按受限额度出售换取金币。

## 已完成：宿主权威结算与数值限制

矿区 iframe 只提交工坊申请，宿主 `js/app.js` 验证请求后才发放资源；iframe 仅在收到成功结果后扣除重复矿石。宿主 bridge 新增按星球保存的 `workshop` 状态，记录 UTC 日期、当日精炼精粹数与出售金币数，并和请求 ID 一起持久化。

- 每日最多精炼 `6` 个星核精粹。
- 每日最多出售获得 `30` 金币。
- 请求 ID 进入 `consumedRequestIds`，重复请求仅返回原成功状态，不会重复加资源。
- 同一天内超出额度的精炼或出售请求被宿主拒绝；次日自动重置对应额度。
- 精炼直接写入 `expedition_material_stellarEssence`，出售通过统一 `addCoins()` 入口结算。

现有装备强化每件从基线到 `+5` 共需 $2 + 4 + 6 + 8 = 20$ 个星核精粹。每日 `6` 个精粹上限将重复矿石转化为稳定但受控的长期进度，不会让矿区成为短周期装备毕业或无限刷金币来源。

## 已启动：星球生态与路线预告

远征玩法的第一阶段从“随机路线”向“可选择的星球生态”推进。每日三颗星球现在各自携带固定且可读的生态预告，玩家在选择星球时就能比较本次远征的收集与路线倾向：

### 生态预告已接入实际遭遇池

生态预告不再只是文案。每颗星球携带可追踪的图鉴属性标签，例如月湾海滩对应 `冰 / 生命 / 水系`，糖晶沙漠对应 `火 / 雷 / 陆地`。宿主在发射远征前会基于这些标签重排战斗节点的图鉴宠物；远征 iframe 也会按相同标签建立 40 只的本次生态池：最多 24 只主题属性宠物，加上最多 16 只非主题宠物。

这样玩家能稳定地为目标属性选择星球，又始终保留少量跨生态的意外相遇。iframe 收到宿主的 `setGameConfig` 后会重新计算生态池，避免启动后的配置更新仍沿用默认随机池。

## 已完成：宠物图鉴、物种成长与重复伙伴循环

本轮先核对了“300 多只宠物 x 五档品质”是否真的对应不同的成长数值。修复前答案是否定的：图鉴虽然已有 `351` 个不同物种，但永久战斗规则只读取 `N / R / SR / SSR / UR` 五套品质基础值和五套每级成长值，物种 ID 没有参与公式。因此当时实际只有品质差异，并不是 `351 x 5 = 1755` 种可培养的战斗面板。

### 物种成长原型

新增稳定物种原型层，以远征物种 ID、名宠 ID、物种 ID、来源 ID、DNA 等稳定字段依次生成可复现的六维属性倾向。每个物种在品质基础模板上拥有约 `0.915` 到 `1.085` 的属性偏向，并附带一个极小的整数指纹，避免低品质属性因取整而出现同面板碰撞。

- 当前 `351` 个物种在 `N / R / SR / SSR / UR` 下形成 `1755` 组互不重复的初始战斗面板。
- 品质仍是主强度来源；物种模板只控制同品质内的战斗方向，不允许普通模板反超下一档品质。
- 每级永久成长保持品质阶梯：`N 1.0`、`R 1.2`、`SR 1.45`、`SSR 1.75`、`UR 2.1`。这让远征升级易读并保证 40 级不会因随机物种偏向出现跨品质倒挂。
- 物种模板也进入成长材料上限，因此同品质伙伴在生命、魔力、攻击、防御、魔法、幸运的可训练方向不同；UR 仍叠加最高基础值、最高每级成长、最高训练空间，以及既有 UR 突变倍率。
- 已有明确 `battle.baseStats` 的旧存档不会被重置；未初始化或仍使用旧品质默认面板的伙伴会自动采用对应物种模板。

宠物详情“永久战斗”区域新增简短的“物种倾向”标签，说明该伙伴最突出的属性，同时明确“品质决定主强度”，避免把物种差异误解成稀有度倒挂。
