## 已完成：星际探险高品质伙伴产出收紧

### 问题与原则

原每日远征按航段顺序推高敌人稀有度，后段会稳定出现史诗和传说敌人；同时残血捕获公式、捕捉增益和 VIP 的品质跃升可以叠加，使 SR / SSR / UR 的实际长期产出偏高。

本轮采用三层约束，保留控血、资源构筑和深层探索的操作价值，同时恢复高品质伙伴的长期目标感：

1. **遭遇权重**：按深度解锁并使用确定性加权抽取，不再按层数稳定发放高品质敌人。
2. **捕获上限**：按来源稀有度设置独立成功率上限，避免捕捉增益将 SSR / UR 堆至接近必成。
3. **品质跃升**：VIP 捕获升档从 `18%` 下调至 `4%`，保留惊喜但不替代长期收集。

### 当前数值基线

| 来源品质 / 对应伙伴品质 | 遭遇节奏 | 单次捕获上限 |
| --- | --- | ---: |
| 普通 / N | 全程主要遭遇 | 45% |
| 稀有 / R | 全程常见，随深度略增 | 32% |
| 精英 / SR | 前段仅极低权重，中后段逐步增加 | 16% |
| 史诗 / SSR | 第 11 层后极低权重解锁 | 7% |
| 传说 / UR | 第 23 层后开放，第 28 层后极低权重 | 2.5% |

- 第 1 至 10 层：普通 `78%`、稀有 `21%`、精英 `1%`；SSR / UR 不会出现。
- 第 11 至 15 层：普通 `72%`、稀有 `25%`、精英 `2.8%`、SSR `0.2%`。
- 第 16 至 22 层：普通 `70%`、稀有 `25%`、精英 `4.5%`、SSR `0.5%`；UR 不会出现。
- 第 23 至 27 层：普通 `65%`、稀有 `27%`、精英 `7%`、SSR `0.9%`、UR `0.1%`。
- 第 28 至 29 层：普通 `58%`、稀有 `29%`、精英 `11%`、SSR `1.8%`、UR `0.2%`。第 30 层为不可捕捉的传说 Boss。

## 进行中：长线成长、挑战远征与友好道馆

### 问题与设计结论

当前伙伴的品质、等级、训练、装备、装备强化、矿区攻击加成和物种远征专精会叠加到远征战斗快照；而常规远征敌人主要按固定章节和层数成长。长期养成后，常规远征会无限接近无风险，强化失去取舍，玩法也会只剩单只高数值伙伴重复刷图。

本轮确定采用“双轨目标”而非把日常远征无限抬高：

1. **常规远征**保留为稳定、快捷的日常资源来源，不让已经培养的伙伴失去爽感。
2. **挑战远征**后续提供危险等级和异变规则，承接高养成阵容；敌方只将超出章节推荐战力的约 `35% - 45%` 转化为补偿，并优先用护盾、蓄能攻击、治疗衰减、环境侵蚀等机制制造策略压力，避免纯数值等比追赶。
3. **装备成长**后续在高强化阶段采用边际递减，并增加路线、生存、资源等横向效果，不只继续叠加攻击。
4. **守护大师友好道馆**作为多伙伴策略入口：首版 5 层、NPC 每层携带 3 只伙伴，玩家选择 3 只轮番车轮战；未来再扩展至 6v6。

### 已实现：道馆资格与爬塔进度核心

- 成功完成远征且奖励首次结算后，累计一次道馆进度；失败、未完成和同一 `runId` 的重复回传不会累计。
- 每成功 2 次远征发放 1 张挑战函，最多持有 2 张；持有已满时不会把错过的发放次数延后补发，避免囤积后瞬间获得大量资格。
- 道馆共 5 层，只能从下一未首通层开始挑战；首通后永久解锁下一层。
- 首次挑战未通关会消耗挑战函；已首通层可反复练习，不再消耗挑战函，胜利奖励固定为首次奖励的 `50%`。
- 进度保存在哈奇远征结算容器中，并已在“今日星图”显示挑战函数量与下一挑战层。

### 已完成：可游玩的 3v3 守护大师友好道馆

- 今日星图新增 3 名未派遣伙伴的道馆编队选择，以及 `1F` 至 `5F` 楼层选择。当前下一层和已首通层可选，后续楼层保持锁定；已通关楼层重打会走减半奖励规则。
- 每层馆主配置固定 3 人阵容，并随楼层递进。道馆直接复用星球远征的 `CombatSystemV2`，没有引入第二套伤害公式；攻击、技能、护甲、敌方意图和动画都沿用正式远征战斗。
- 对战中击败守卫会自动切换下一名守卫；己方伙伴倒下会自动切换下一名伙伴。三名守卫全部击败才算胜利，三名己方伙伴全部倒下或主动离开则判定失败。
- 对战结果由 iframe 统一回传给父端结算；挑战 `runId` 保持幂等，避免重复消息造成重复扣函或重复发奖。道馆返回操作会先请求 iframe 放弃本局，再由同一结算路径返回星图。
