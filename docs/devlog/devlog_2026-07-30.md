# 2026-07-30 开发日志（进行中）

今天的工作主线是继续把“哈奇星球远征”从一个独立小游戏，补强为可持续成长的玩法系统，同时继续守住一个边界：**所有新增能力只对哈奇星球生效，不改变蛋蛋星球及其他星球的玩法。**

## 已完成：远征可靠性与隔离收口

昨天遗留的远征失败问题已完成修复并回归验证：

- 宠物被击败后，已捕获伙伴会被清空，不能再携带离开。
- 失败后不会进入空的携带选择流程，不会卡回战斗界面。
- 失败结算不会发放经验、材料、战利品或捕获宠物。
- VIP 失败不会消耗通行资格。
- 宿主结算层也会拒绝 `completed !== true` 或 `passed !== true` 的结果，避免小游戏异常结果绕过前端。
- 已对失败分支做浏览器回归：失败后捕获数为 `0`、不打开携带结算、存在可用的退出按钮。

此前修复已上传；而今天新增的隔离和成长系统仍只保存在本地，按约定等待今晚统一上传。

## 已完成：哈奇星球专属插件边界

新增哈奇远征插件边界，所有开关按精确 `planetId === 'haqi'` 判断，不依赖星球显示名称：

- 蛋蛋星球不显示“星球探险”入口。
- 非哈奇星球无法进入远征路线，也不会应用远征结算或捕获结果。
- 哈奇远征进度使用独立的 `haqiExpeditionSettlement` 命名空间，不再混入通用星球设置。
- 新增的家园珍宝设施、装备系统也增加了哈奇星球门禁。

这部分的目标是让哈奇玩法可以继续扩展，同时避免无意影响蛋蛋星球现有经济、宠物养成与家具玩法。

## 已完成：家园珍宝转为可摆放设施

原先的家园珍宝是“背包中直接领取每日奖励”。现在已完成第一版设施化：

- 四种珍宝可作为唯一设施摆放到哈奇星球野外地块。
- 设施只在摆放后运行，未摆放时不能领取每日效果。
- 背包会显示“未摆放 / 已运行”、设施等级和累计运行天数。
- 每成功领取一天效果，设施累计运行天数增加；每 7 天提升一级，形成长期成长反馈。
- 复用了既有的家具布局和保存体系，不新增第二套场景或摆放存档。
- 从背包点击“摆放”会进入野外地块装修模式；野外托盘可看到已拥有的珍宝设施。

设施成长已在本轮数值化：每提升 1 级，珍宝每日产出增加 `10%`，最高额外增加 `50%`。这样既能让长期运营有明确收益，也限制了星币与生物燃料的经济膨胀。

## 已完成：繁育决策体验第一版

现在玩家能够理解“这对亲代为什么值得配”，而不是只靠猜测配对。

## 已完成：独立装备系统第一版

新增独立装备规则层，并接入宠物永久战斗面板：

- 三个装备槽：徽记、晶核、护甲。
- 当前提供三件起始远征装备，用于验证完整装备流程。
- 宠物面板可装配、替换、卸下装备，变化后立即重算属性。
- 装备持有记录保存在哈奇远征专属进度中，不进入通用背包经济。
- 远征发射前会显式使用装备后的派生属性。

规则已固定并展示在宠物面板中：

$$
\text{最终属性}
=
(\text{品质基础} \times \text{基础倍率}
+
\text{成长} \times \text{成长倍率}
+
\text{训练}
+
\text{装备固定值})
\times
\text{装备百分比}
$$

这意味着：

- UR 倍率只作用于品质基础与成长部分。
- 训练值不会被 UR 放大。
- 装备固定属性也不会被 UR 放大。
- 仅装备自身带有百分比效果时，才在最后一步进行倍率计算。
- 普通星球默认计算不包含装备，避免哈奇装备提升带到蛋蛋星球。

## 本轮双端回归与结算收口

本轮在桌面 `1440 x 900` 与手机 `390 x 844` 视口重新检查了哈奇远征页面。两端均无横向溢出，30 个星图节点与“进入星图”入口可见。连续 40 轮强化候选均稳定返回 4 张不同卡牌。

复测中发现一个结算漏洞：玩家在没有击败最终首领时主动退出，若运行态尚未显式标记 `failed`，小游戏会错误发送 `completed = true`，并可能携带已捕获伙伴、材料及装备掉落。

- 结算成功条件已收紧为 `bossDefeated && !failed`。
- 未完成或失败退出时，`completed`、`passed` 与 `bossDefeated` 均为 `false`。
- 同类结果会清空 `captures`、`loot`、`equipmentDrops` 和家园珍宝；宿主的既有二次校验继续作为防线。
- 修复后实际报文复测为 `completed = false`、`passed = false`，且捕获宠物、材料、装备掉落全部为空。

入口与隔离也重新验证：显式哈奇游客入口在真实菜单中显示“星球探险”；默认蛋蛋星球在手机视口下没有该入口且无横向溢出。哈奇功能门禁仍只接受精确的 `planetId = 'haqi'`，没有向其他星球放宽。
