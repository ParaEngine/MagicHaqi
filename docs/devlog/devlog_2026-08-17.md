## 远征战术技能数值重平衡

- 学习获得的战术芯片此前只按攻击结算，在高魔法伙伴身上没有成长价值，且高 MP 输出与满蓄力星核爆裂缺少可感知分工。
- 攻击型芯片现统一按“攻击 + 魔法的 60%”计算魔导强度。糖果陨石、星爆脉冲、彗星突刺与潮汐连射重新分档为爆发技能；其中陨石和星爆可以在合适构筑下超过满 MP 星核的单次伤害。
- 续航与控制型芯片同步调整为低于终结技的资源门槛：纳米修复恢复 45% 生命，泡泡壁垒提供 42% 最大生命护盾，霜冻脉冲和破甲震荡分别压低敌方下一击 50% 与 35%。
- 固定验收场景使用攻击 `80`、魔法 `60`、最大 MP `100`，对应魔导强度 `116`：满 MP 星核实测 `422` 伤害；糖果陨石 `429`，星爆脉冲 `452`，潮汐连射 `406` 且击杀返还 `30 MP`。攻击芯片现拥有明确的爆发和效率选择，不再被星核完全覆盖。
- `npm run upload` 构建通过，远征页诊断无错误；浏览器已验证所有调整后的技能按钮可见、可用，并能进入真实 `CombatSystemV2` 结算。

## 道馆数值审计

- 当前 1F 至 5F 的三名守卫总生命依次为 462、634、876、1,196、1,679；总攻击依次为 126、181、258、365、546，整体曲线单调上升。
- 道馆直接复用星球远征的战斗引擎：三名守卫会共享同一位出战伙伴的生命和 MP 节奏，不享受普通远征路线中的临时强化。后续首通率应以整队总生命、总攻击、平均回合数和倒下的出战位来校准，不能按单只伙伴评估。
- 审计发现守卫的 `defense` 目前未参与 `CombatSystemV2` 对敌伤害结算；本轮未强行改变此行为，以免干扰既有技能和连击包装。下轮如要启用防御型守卫，需在战斗引擎中正式支持敌方护甲，再为普通攻击、技能、暴击和护盾建立统一的可测试减伤规则。

## 长线远征压力

- 常规远征保留原有“普通 / 挑战 / 危险”路线档位；新增随伙伴实际战力生效的星图压力，避免装备、训练和矿区加成无限累计后把 30 层路线变成纯数值碾压。
- 压力同时参考攻击、魔法、生命与防御。低于基准战力时不加难度；超过基准后，敌方生命和伤害只吸收 42% 的超额成长，最多额外提高 80%。这保证成长始终有效，但不会等比例放大到让后期强度失控。
- 星图入口和开场简报均展示“标准”或“星图压力 +X%”，玩家可以在出发前判断压力，不会在战斗中遭遇未说明的数值变化。
- 已为压力计算建立独立单元测试，覆盖混合属性计算、基准免加压、单调增长与 80% 封顶。

## 美术资源公网发布规则

- 新增或替换的运行时美术资源不得依赖 Keepwork `api/raw` 页面的相对 `./assets/...` 路径；公开 raw 页面无法稳定提供这类媒体文件。
- 发布顺序固定为：先上传到 `https://cdn.keepwork.com/` 的稳定媒体前缀，再将运行时 `src`、`iconSrc` 或 CSS `url(...)` 改为绝对 CDN 地址，代码模块仍由原页面加载，不迁移到 CDN。
- 提交前必须从公开页面或浏览器对至少一个新增资源执行请求验证，确认响应为 `200` 且 `content-type` 为对应图片类型；页面内图片还应确认 `naturalWidth > 0`。未通过不得提交为已发布状态。

## 候选优化方向

### 1. 道馆首轮实战平衡与反馈

- 收集 1F 至 5F 的首通率、平均战斗轮数、失败节点和三人编队使用情况。
- 校准馆主属性、护盾反击主题和奖励，保证早期有策略空间，后期仍需要养成与阵容搭配。
- 补足战斗内的出战顺序、换人和胜负结算反馈，让玩家容易理解 3v3 规则。

### 2. 长线成长的上限与横向选择

- 让高强化装备、训练和矿区加成继续带来成长，但通过边际递减、流派效果和挑战异变避免常规内容被无限碾压。
- 将高阶成长更多投向生存、资源、路线与技能协同，而不是持续叠加纯攻击。

### 3. 挑战远征原型

- 在常规远征之外增加可选危险等级与异变规则，作为高养成玩家的长期目标。
- 敌方仅吸收超出推荐战力的一部分，并通过护盾、蓄能、治疗衰减、环境侵蚀等机制形成策略压力。

### 4. 宠物编队与战斗信息架构

- 为 3v3 / 后续 6v6 建立明确的编队预设、出战顺序、属性对比和技能定位展示。
- 让玩家在进入道馆或挑战远征前能够读懂队伍短板与推荐准备。

### 5. 每日远征的中段决策密度

- 丰富 30 层远征中营地、商人、事件和精英战之间的可控取舍。
- 保持稀有伙伴收紧后的长期收集节奏，同时让每次远征除捕捉外还有不同构筑体验。
